
# 📊 Pandas & Matplotlib Analysis — Iris Dataset

This project analyzes the classic Iris dataset using Python libraries: pandas, matplotlib, and seaborn.

## ✅ Objectives
- Load and explore data with pandas.
- Analyze basic statistics.
- Visualize insights with 4 types of plots.

## 📁 Files Included
- `pandas_assignment.py`: Full analysis and visualization script.
- `line_chart.png`: Sepal length trend line chart.
- `bar_chart.png`: Average petal length by species.
- `histogram.png`: Distribution of petal width.
- `scatter_plot.png`: Sepal vs. Petal length scatter plot.

## 📌 Requirements
- Python 3.x
- `pandas`, `matplotlib`, `seaborn`, `sklearn`

## 🚀 How to Run
```bash
python pandas_assignment.py
```

All plots will be saved in the same directory.

## 🔍 Observations
- Setosa has the smallest petal length.
- Petal width has a right-skewed distribution.
- Strong positive correlation between sepal and petal length.
